EB Garamond — the serif LoudFlow ships for the Hub's stat numbers and serif headings
====================================================================================

WHAT IS HERE
  EBGaramond-Variable.woff2           112 424 bytes  subset "latin"
                                      sha256 650a8f6173ab34515a53f362bbdc2d40a89ae14207ba1263b5cb12acde1a5eb7
  EBGaramond-Variable-ext.woff2       121 396 bytes  subset "latin-ext"
                                      sha256 22f9c7935ceb95b581b812ba5593fb536bc56a93072d8d224ed729fa85c0497b
  Total shipped: 233 820 bytes. Both files carry the wOF2 magic (verified by
  fontTools on the build, and by app/test/hubfonts.test.js on every run).

  Axis: weight 400..800 — the files' own fvar table, read back after the build,
  and what @font-face declares at app/src/hub/skeleton.css. The unicode-range on
  each face is the same "latin" / "latin-ext" split skeleton.css already
  declares for Instrument Sans, so Chromium fetches the -ext file only when a
  glyph outside latin appears. Upright only: the Italic master in the extract
  was not built, because nothing in the Hub sets a serif italic yet.

WHERE THEY CAME FROM
  Upstream project   https://github.com/octaviopardo/EBGaramond12
                     (Georg Duffner, Octavio Pardo — the font's own name table, IDs 8/9)
  Source file        EBGaramond-VariableFont_wght.ttf, 936 656 bytes, "Version 1.001",
                     as shipped inside Wispr Flow 1.6.606 at
                     resources/assets/fonts/EBGaramond/ and unpacked on this machine
                     on 2026-08-26 (LOUDFLOW-WORKSPACE/wispr-flow-reference-1.6.606/).
  Built on 2026-09-02 with fontTools 4.63.0 + brotli, offline
  (Subsetter with flavor=woff2, layout_features=['*'], name_IDs=['*'],
  name_languages=['*'], notdef_outline=True — the whole name table, every
  OpenType feature and the weight axis kept; only the glyphs outside each
  unicode-range dropped). This is a Modified Version in the OFL's sense: a
  subset in a new container, the same thing Google Fonts serves for the
  family. NOTHING WAS DOWNLOADED FOR LOUDFLOW and nothing is fetched at
  runtime: the Hub's Content-Security-Policy is `font-src 'self'` with
  `connect-src 'none'`.

  Wispr Flow sets this face through its `heading-serif` mixin (weight 400,
  letter-spacing -0.04em, steps 28/36/48/72 px): ui-extract/source/src/renderer/
  styles/system.module.scss lines 210, 227-230, 251-254 and 348-351 of the
  1.6.606 extract. Those numbers are the --sk-serif-* tokens in skeleton.css.
