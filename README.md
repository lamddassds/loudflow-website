# LoudFlow Website

Marketing & download site for LoudFlow — deployed to [loudflow.xyz](https://loudflow.xyz).

## Stack

- Next.js 15 (App Router)
- Tailwind CSS
- Framer Motion
- Deployed on Vercel

## Local dev

```bash
cd website
npm install
npm run dev
```

Opens at http://localhost:3000

## Deployment

Auto-deployed to Vercel on every push to `main`.
The `Download` buttons point at the latest GitHub Release of the Electron app:
`https://github.com/lamddassds/Loudflow-updat/releases/latest`
